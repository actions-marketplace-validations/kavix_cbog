# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest| :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please do NOT report it in public GitHub issues or discussions.

Instead, please report security issues via:
- GitHub Private Vulnerability Reporting (Security tab -> Report a vulnerability)
- Or contact repository maintainers directly.

### What to Include in Your Report
- A description of the vulnerability and its potential impact.
- Clear steps to reproduce the issue (including any proof-of-concept code).
- Any proposed remediation or patches, if available.

### Response Timeline
- Maintainers will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide status updates as we investigate and develop a security patch.
- Once fixed, a security advisory and patched release will be published.
