# Getting Support

Thank you for using **cbog**. Here are the best ways to get help and report issues.

---

## 1. Documentation
Please check our [README.md](README.md) and configuration guide for quickstart workflows and `.github/cbog.yml` customization options.

---

## 2. Asking Questions
For general questions, architecture discussions, or feature ideas:
- Open an issue with the `question` label.
- Or start a conversation with the maintainers.

---

## 3. Reporting Bugs
If you have found a bug in `cbog`:
1. Search [existing issues](https://github.com/kavix/cbog/issues) to avoid duplicates.
2. Open a new issue using our structured **Bug Report** form.
3. Include your runner OS, workflow file, and steps to reproduce.

---

## 4. Security Disclosures
For security concerns, please refer to our [Security Policy](SECURITY.md) to report vulnerabilities privately.
