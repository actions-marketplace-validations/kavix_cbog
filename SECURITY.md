# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

We take the security of `cbog` seriously. If you discover a security vulnerability or potential privilege escalation:

Please do **NOT** report it publicly on GitHub issues.

Instead, please report vulnerabilities via:
- GitHub Security Advisories: Click **Security** -> **Report a vulnerability** on this repository.
- Or email the maintainer directly.

### What to Include
- Detailed description of the vulnerability and attack vector.
- Reproduction steps or proof of concept.
- Affected configuration or plugin.

### Response Timeline
- Maintainers will acknowledge reports within 48 hours.
- A fix and security release will be published promptly after verification.
