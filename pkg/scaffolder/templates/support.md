# Getting Support

Thank you for using our project. Here are the recommended channels to get help, ask questions, and report issues.

---

## 1. Documentation & Guides
Before opening an issue, please check our documentation and `README.md`. Many common questions and configurations are covered there.

---

## 2. Asking Questions & Discussions
For general questions, design ideas, or troubleshooting:
- Open a discussion in [GitHub Discussions](https://github.com/{{.Owner}}/{{.Repo}}/discussions)
- Or reach out to the maintainers and community.

Please do not open bug reports for general usage questions.

---

## 3. Reporting Bugs
If you have identified a confirmed bug:
1. Search existing issues to ensure it has not already been reported.
2. File a new issue using our structured **Bug Report** form.
3. Provide clear reproduction steps, environment details, and expected behavior.

---

## 4. Security Vulnerabilities
If you have discovered a security issue, please do NOT report it publicly. Refer to our [Security Policy](SECURITY.md) for instructions on confidential disclosure.
